# 포켓몬 카드 시세 보드 (pokewatch)

네이버 카페 장터 게시글을 모아서 **어떤 카드가 얼마인지 한눈에** 볼 수 있게 정리해 주는
프로그램입니다. 글 제목에서 카드 이름·레어도·언어·감정 등급·가격을 자동으로 뽑아내
같은 카드끼리 묶고, 카드별 시세(최저·중앙값·최고)와 가격 추이를 웹 대시보드로 보여줍니다.

- 파이썬 **표준 라이브러리만** 사용합니다. 설치할 패키지가 없습니다.
- 데이터는 로컬 SQLite 파일에 쌓이므로, 계속 돌릴수록 시세 추이가 길어집니다.
- 네트워크 없이 화면을 먼저 보고 싶으면 `demo` 명령으로 예제 데이터를 넣을 수 있습니다.

---

## 1. 바로 실행해 보기

```bash
python3 -m pokewatch demo
```

예제 데이터 420건을 만들고 <http://127.0.0.1:8765> 에 대시보드를 띄웁니다.
(실제 카페 글이 아니라 한국 장터에서 흔한 제목 형식을 흉내 낸 가짜 데이터입니다.)

## 2. 실제 카페 연결하기

```bash
# 1) 설정 파일 만들기
python3 -m pokewatch init

# 2) 카페의 게시판 ID 확인하기
python3 -m pokewatch menus 카페주소        # 예: python3 -m pokewatch menus pokemontcgkr

# 3) config.json 을 채운 뒤 수집
python3 -m pokewatch collect

# 4) 대시보드 열기
python3 -m pokewatch serve
```

`카페주소` 는 `https://cafe.naver.com/` 뒤에 붙는 부분입니다.

### config.json 예시

```json
{
  "db_path": "data/pokewatch.db",
  "delay": 0.8,
  "port": 8765,
  "cafes": [
    {
      "name": "포켓몬카드 카페",
      "cafe_url": "카페주소",
      "menu_name_filter": ["장터", "거래", "판매"],
      "pages": 3,
      "per_page": 50
    }
  ]
}
```

| 항목 | 설명 |
|---|---|
| `cafe_url` | 카페 주소. 숫자 `club_id` 를 이미 알면 `"club_id": 12345678` 로 대신 써도 됩니다. |
| `menu_ids` | 수집할 게시판 ID 목록. `menus` 명령으로 확인합니다. |
| `menu_name_filter` | ID 대신 게시판 **이름**에 포함된 단어로 고릅니다. |
| `pages` | 게시판별 수집 페이지 수 (한 페이지 최대 50건). |
| `delay` | 요청 사이 대기 시간(초). 줄이지 마세요. |

### 회원 전용 게시판

로그인해야 보이는 게시판은 브라우저 쿠키가 필요합니다. 로그인한 상태에서 개발자 도구의
Network 탭 요청 헤더에 있는 `NID_AUT`, `NID_SES` 값을 복사해 환경변수로 넘기세요.

```bash
export POKEWATCH_COOKIE="NID_AUT=...; NID_SES=..."
python3 -m pokewatch collect
```

쿠키는 로그인 세션 그 자체이므로 절대 저장소에 커밋하지 마세요. 그래서 설정 파일보다
환경변수를 우선하도록 만들어 두었습니다.

## 3. 대시보드에서 볼 수 있는 것

- **카드 격자 보기** — 카드 이미지(글 썸네일), 이름/영문명/도감번호, 레어도·언어·감정 배지,
  중앙값 가격, 최저~최고 범위, 최근 시세 스파크라인, 상승/하락률
- **표 보기** — 같은 내용을 정렬 가능한 표로
- **카드 상세** — 일자별 중앙값 그래프, 거래 유형/상태 분포, 원본 글 목록(클릭 시 카페로 이동)
- **필터** — 검색어, 거래 유형(판매/구매/교환), 레어도, 언어, 기간, 감정 카드만, 일괄 제외
- 상단 **새로 수집** 버튼으로 대시보드를 켜 둔 채 다시 수집할 수 있습니다.

시세 계산은 **판매글의 단일 카드 가격만** 사용합니다. 구매 희망가와 일괄 판매가는
실제 시세를 왜곡하기 때문에 중앙값 계산에서 빠지고, 상세 화면에는 그대로 보입니다.

글에 썸네일이 없으면 레어도 색으로 칠한 대체 카드 이미지를 그려서 보여 줍니다.

## 4. 터미널에서 보기

```bash
python3 -m pokewatch top -n 20 --sort price   # 비싼 순
python3 -m pokewatch top --sort trend --days 30
```

```
  카드                                   중앙값        최저        최고    매물  추이
  ──────────────────────────────────────────────────────────────────────────────────
  릴리에 슈퍼 레어 (일판)             85.2만원      61.8만원     108.5만원    23  ▲ +10.4%
  블래키 VMAX (일판)                  56.3만원      51.1만원      63.6만원    16  ─ +0.8%
```

제목 하나가 어떻게 해석되는지 확인할 수도 있습니다.

```bash
python3 -m pokewatch parse "[판매] 리자몽 ex SAR (한글) SV5a 165/165 상태 S급 18만원 택포"
```

## 5. 제목 해석 방식

한국 장터 글 제목에서 다음을 뽑아냅니다.

| 항목 | 인식 예 |
|---|---|
| 거래 유형 | 판매/팝니다/분양, 삽니다/구합니다, 교환, 나눔 |
| 가격 | `12만`, `12.5만`, `12만5천`, `85,000원`, `120000`, `55k`, `12~15만` |
| 레어도 | SAR, SR, AR, UR, HR, CHR, CSR, RR, ex, V, VMAX, VSTAR, GX, 프로모, 풀아트 |
| 언어 | 한글/한판/정발, 일판/일본, 영문/미판 |
| 감정 | PSA 10, BGS 9.5, CGC, ARS |
| 상태 | 미개봉, 민트/S급, 니어민트/A급, 플레이드/흠집 |
| 부가 정보 | 세트 코드(SV5a), 카드 번호(165/165), 수량, 택포, 일괄, 네고 |

가격처럼 생겼지만 가격이 아닌 숫자는 걸러냅니다. 카드 번호(`165/165`), 감정 점수(`PSA 10`),
수량(`10장`), 연도(`2024년`)가 대표적입니다. `가격제시`, `쪽지주세요` 같은 표현이 있으면
가격 미기재로 둡니다.

### 같은 카드로 묶는 기준

`카드이름 | 레어도 | 언어` 를 키로 씁니다. 세트 코드와 카드 번호는 일부 글에만 적혀 있어서
키에 넣으면 같은 카드가 잘게 쪼개집니다. 언어를 안 적은 글은, 그 카드의 언어가 한 가지뿐일
때만 그쪽으로 합치고 한글·일판이 섞여 있으면 `미표기`로 따로 둡니다.

### 카드 이름 사전 넓히기

`pokewatch/data/pokemon_ko.json` 에 포켓몬 약 180종과 서포트 카드가 들어 있습니다.
자주 거래되는데 인식이 안 되는 카드가 있으면 이 파일에 추가하고 다시 해석하세요.

```bash
python3 -m pokewatch reparse   # 다시 수집하지 않고 저장된 제목만 재해석
```

## 6. 명령어 목록

| 명령 | 설명 |
|---|---|
| `init` | `config.json` 템플릿 생성 |
| `menus <카페주소>` | 게시판 목록과 ID 조회 |
| `collect` | 설정된 카페에서 글 수집 |
| `serve` | 대시보드 실행 |
| `demo` | 예제 데이터 생성 후 대시보드 실행 |
| `top` | 터미널에서 시세 상위 카드 보기 |
| `parse "<제목>"` | 제목 하나의 해석 결과 확인 |
| `reparse` | 저장된 제목을 현재 파서로 재해석 |

주요 환경변수: `POKEWATCH_COOKIE`, `POKEWATCH_DB`, `POKEWATCH_PORT`, `POKEWATCH_CONFIG`

## 7. 구조

```
pokewatch/
  naver.py           네이버 카페 JSON API 클라이언트 (재시도·요청 간격 제어)
  parsing/
    price.py         한국어 가격 표기 → 원 단위 정수
    cardinfo.py      제목 → 카드 정보(레어도·언어·감정·상태·거래유형)
    pokedex.py       한글/영문 카드 이름 사전과 최장 일치 매칭
  stats.py           매물 → 카드별 시세 요약, 추이, 일자별 중앙값
  db.py              SQLite 저장소
  pipeline.py        수집 파이프라인
  server.py          대시보드 HTTP 서버 + JSON API
  web/               대시보드 화면 (외부 라이브러리 없음)
  demo.py            예제 데이터 생성기
```

## 알아 두실 점

- **시세는 참고용입니다.** 글 제목에서 자동으로 뽑은 호가라서, 실제 체결가와 다르고
  허위 매물이나 오타가 섞일 수 있습니다. 매물 수가 적은 카드일수록 오차가 큽니다.
- **개인적인 시세 확인 용도로만 사용하세요.** 요청 간격(`delay`)을 줄이거나 대량으로
  긁지 마세요. 카페 운영 정책과 `robots.txt` 확인, 로그인 쿠키 관리는 사용자 책임입니다.
- 네이버가 내부 API 응답 형식을 바꾸면 수집이 실패할 수 있습니다. 그럴 때는
  `python3 -m pokewatch -v collect` 로 로그를 확인하세요.
- 이 저장소가 만들어진 환경에서는 네이버 도메인이 네트워크 정책으로 차단되어 있어,
  **수집기는 실제 카페 응답으로 검증하지 못했습니다.** 파싱·집계·대시보드는 예제
  데이터와 단위 테스트로 검증했습니다. 처음 `collect` 를 돌릴 때는 `-v` 로 로그를 보며
  `pages` 를 1로 두고 시작하시길 권합니다.
