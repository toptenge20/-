# 포켓몬 카드 시세 보드 (pokewatch)

네이버 카페 장터 게시글을 모아서 **어떤 카드가 얼마인지 한눈에** 볼 수 있게 정리해 주는
프로그램입니다. 글 제목에서 카드 이름·레어도·언어·감정 등급·가격을 자동으로 뽑아내
같은 카드끼리 묶고, 카드별 시세(최저·중앙값·최고)와 가격 추이를 웹 대시보드로 보여줍니다.

- 파이썬 **표준 라이브러리만** 사용합니다. 설치할 패키지가 없습니다.
- 더블클릭으로 켜지는 **데스크톱 앱**이자, 휴대폰 홈화면에 설치되는 **PWA** 입니다.
- **컴퓨터 없이 폰만으로도** 쓸 수 있습니다. 클라우드가 대신 수집하고 폰은 주소만 엽니다. → 2번
- 데이터는 로컬 SQLite 파일에 쌓이므로, 계속 돌릴수록 시세 추이가 길어집니다.
- 네트워크 없이 화면을 먼저 보고 싶으면 그냥 실행하세요. 예제 데이터가 자동으로 들어갑니다.

---

## 1. 앱으로 실행하기

**더블클릭 한 번**으로 켜집니다. 운영체제에 맞는 파일을 실행하세요.

| 운영체제 | 실행 파일 |
|---|---|
| 맥 | `실행_맥.command` (처음엔 오른쪽 클릭 → **열기**) |
| 윈도우 | `실행_윈도우.bat` |
| 리눅스 | `실행_리눅스.sh` |

또는 터미널에서:

```bash
python3 app.py              # 앱 창으로 실행
python3 app.py --lan        # 휴대폰에서도 접속할 수 있게 실행
python3 app.py --no-window  # 서버만 실행
```

처음 켜면 데이터가 없으므로 예제 데이터를 자동으로 넣어 화면을 보여 줍니다.
실제 카페를 연결하려면 아래 3번을 보세요.

- `pywebview` 를 설치하면(`pip install pywebview`) 주소창 없는 **전용 앱 창**으로 열립니다.
  없으면 기본 브라우저로 열립니다.
- 시세 DB는 소스 폴더가 아니라 OS별 사용자 데이터 폴더에 저장됩니다
  (맥 `~/Library/Application Support/pokewatch`, 윈도우 `%APPDATA%\pokewatch`,
  리눅스 `~/.local/share/pokewatch`). 앱을 옮기거나 다시 받아도 시세 기록이 남습니다.
- 포트가 이미 쓰이고 있으면 알아서 빈 포트를 찾습니다. 두 번 켜도 죽지 않습니다.

## 2. 핸드폰만으로 쓰기 (컴퓨터 없이)

컴퓨터를 켜 두지 않고 폰만으로 쓰는 방법은 두 가지입니다.

### 방법 A — 클라우드가 대신 수집 (아이폰·안드로이드 모두)

**깃허브 액션**이 정해진 시간마다 카페 글을 수집해 정적 사이트로 만들고,
**Cloudflare Pages** 에 올립니다. 폰은 그 주소를 열어 홈화면에 추가하기만 하면 됩니다.

**컴퓨터는 필요 없습니다.** 아래 과정은 전부 폰 브라우저에서 할 수 있습니다.
(파이썬 설치도, 코드 내려받기도 하지 않습니다.)

> 📱 **처음이시라면 [설치_따라하기.md](설치_따라하기.md) 를 보세요.**
> 버튼 하나하나까지 그대로 따라 하도록 적어 두었습니다. 아래는 요약입니다.

Cloudflare Pages 를 쓰는 이유는 **비공개 저장소도 무료로 서비스**해 주기 때문입니다.
(깃허브 페이지는 무료 요금제에서 비공개 저장소를 지원하지 않습니다.)

#### 1) 코드를 main 브랜치로 합치기 ⚠️ 꼭 필요합니다

깃허브의 **예약 실행(cron)은 기본 브랜치(main)에 있는 워크플로만** 동작합니다.
작업 브랜치에 두면 자동 수집이 영영 돌지 않습니다.

깃허브 앱이나 폰 브라우저에서 저장소 → **Pull requests → New pull request** →
`claude/naver-cafe-pokemon-cards-0i0yz0` → `main` 으로 만들고 **Merge** 하세요.

#### 2) Cloudflare 준비 — [dash.cloudflare.com](https://dash.cloudflare.com) 가입(무료)

- **계정 ID**: 로그인 후 주소창의 `dash.cloudflare.com/<여기가 계정ID>` 부분
- **API 토큰**: 오른쪽 위 프로필 → **API Tokens** → **Create Token**
  → **Edit Cloudflare Workers** 템플릿 → 계정 선택 후 생성 (Pages 배포 권한 포함)
  → **토큰은 이때 한 번만 보입니다. 바로 복사해 두세요.**

#### 3) 깃허브 시크릿 등록 — 저장소 **Settings → Secrets and variables → Actions**

**New repository secret** 으로 하나씩 추가합니다.

| 이름 | 값 | 필수 |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | 위에서 만든 토큰 | 예 |
| `CLOUDFLARE_ACCOUNT_ID` | 계정 ID | 예 |
| `POKEWATCH_CONFIG_JSON` | 아래 설정 내용 | 나중에 추가해도 됨 |
| `POKEWATCH_COOKIE` | `NID_AUT=...; NID_SES=...` | 회원 전용 게시판일 때만 |

`POKEWATCH_CONFIG_JSON` 에 넣을 내용은 이게 전부입니다. **게시판 ID를 몰라도 됩니다.**
게시판 *이름*에 이 단어들이 들어간 곳을 알아서 찾습니다.

```json
{
  "cafes": [
    {
      "name": "포켓몬카드 카페",
      "cafe_url": "카페주소",
      "menu_name_filter": ["장터", "거래", "판매"],
      "pages": 3
    }
  ]
}
```

`cafe_url` 에는 카페를 가리키는 것이면 무엇이든 넣을 수 있습니다.

| 넣을 수 있는 값 | 예 |
|---|---|
| 카페 주소 | `pokecardkorea` |
| 전체 주소 | `https://cafe.naver.com/pokecardkorea` |
| 모바일 주소 | `https://m.cafe.naver.com/ca-fe/web/cafes/12345678/...` |
| **공유 짧은 링크** | `https://naver.me/xxxxxxxx` |
| 숫자 ID | `"club_id": 12345678` 로 지정 |

휴대폰에서는 카페 앱의 **공유 → 링크 복사** 로 얻은 짧은 링크밖에 없는 경우가 많아서,
수집기가 리다이렉트를 따라가 실제 카페 ID를 찾아내도록 했습니다.

사이트 이름을 바꾸려면 같은 화면의 **Variables** 탭에 `CF_PAGES_PROJECT` 를
추가하세요 (기본값은 `pokewatch-<깃허브아이디>` 라서 보통 그냥 두면 됩니다).

#### 4) 첫 실행 — **Actions → 시세 수집 후 사이트 갱신 → Run workflow**

2~3분 뒤 로그에 `앱 주소 → https://pokewatch-<아이디>.pages.dev` 가 찍힙니다.

> 카페 설정(`POKEWATCH_CONFIG_JSON`)을 아직 안 넣었다면 **예제 데이터로 사이트가
> 만들어집니다.** 화면부터 확인하고 나중에 카페를 연결해도 됩니다.

#### 5) 아이폰에 설치 — 사파리로 그 주소를 열고 **공유 → 홈 화면에 추가**

사파리에는 설치 버튼 API 가 없어서, 처음 열면 화면 위에 안내 띠가 한 번 뜹니다.
안드로이드 크롬이면 메뉴 → **앱 설치**.

이제 끝입니다. HTTPS 주소라서 **오프라인 캐시까지 완전히 동작합니다.** 지하철처럼
신호가 없는 곳에서도 마지막으로 받아 둔 시세가 그대로 보입니다. 수집 주기는
`.github/workflows/collect.yml` 의 `cron` 에서 바꿉니다
(기본: 한국시간 오전 9시·오후 9시).

> **미리 알아 두실 점**
> - 네이버가 데이터센터 IP를 막을 수 있어 **클라우드에서 수집이 실패할 가능성이 있습니다.**
>   이 환경에서는 네이버가 차단되어 있어 실제로 확인하지 못했습니다. 실패해도 사이트는
>   지난 스냅샷으로 유지되고 Actions 로그에 경고가 남습니다. 막힌다면 가끔 컴퓨터에서
>   `collect` → `export` 한 뒤 `site/` 폴더만 올리는 방식으로도 쓸 수 있습니다.
> - Cloudflare 시크릿을 등록하지 않아도 워크플로는 돌아가며, 만들어진 `site` 폴더를
>   **Actions 아티팩트**로 내려받아 원하는 곳에 직접 올릴 수 있습니다.

### 방법 B — 폰 안에서 전부 실행 (안드로이드 전용, 계정 불필요)

> 아이폰에는 해당하지 않습니다. iOS 에는 Termux 같은 리눅스 환경이 없어서
> 아이폰이라면 위의 **방법 A** 를 쓰세요.

**Termux** 를 쓰면 수집기와 서버가 폰 안에서 돕니다. 컴퓨터도 클라우드 계정도 필요 없습니다.

1. [F-Droid](https://f-droid.org/packages/com.termux/) 에서 **Termux** 설치
   (플레이스토어 버전은 오래돼서 안 됩니다)
2. Termux 에서:
   ```bash
   pkg install -y git
   git clone <이 저장소 주소> && cd <폴더>
   bash termux_설치.sh
   ```
3. `nano config.json` 으로 카페 설정 → `python3 -m pokewatch collect`
4. `pokewatch` 로 앱 실행 → 크롬에서 `http://localhost:8765` → **홈 화면에 추가**

`localhost` 는 보안 컨텍스트라 **오프라인 캐시까지 전부 동작합니다.**
설치 스크립트가 60분마다 자동 수집하도록 잡아 두고, Termux:Boot 앱을 깔면 폰을 켤 때
자동으로 실행됩니다. 안드로이드가 앱을 죽이지 않도록 Termux 알림에서
**Acquire wakelock** 을 켜 두세요.

### 참고 — 집 컴퓨터와 같은 와이파이로 쓰기

컴퓨터에서 `python3 app.py --lan` 을 켜고 표시되는 `http://192.168.x.x:8765` 로
접속해도 됩니다. 다만 LAN 주소는 브라우저가 보안 컨텍스트로 보지 않아
**오프라인 캐시가 동작하지 않고**, 컴퓨터가 켜져 있어야 합니다.

### 데스크톱에 설치하기

크롬·엣지에서 주소창의 설치 아이콘 또는 화면 오른쪽 위 **앱 설치** 버튼을 누르면
독립된 창을 가진 앱이 됩니다. 서버가 꺼져 있어도 마지막 시세를 보여 줍니다.

## 3. 실제 카페 연결하기

```bash
# 1) 설정 파일 만들기
python3 -m pokewatch init

# 2) 카페의 게시판 ID 확인하기
python3 -m pokewatch menus 카페주소        # 예: python3 -m pokewatch menus pokemontcgkr

# 3) config.json 을 채운 뒤 수집
python3 -m pokewatch collect

# 4) 대시보드 열기
python3 -m pokewatch serve
```

`카페주소` 는 `https://cafe.naver.com/` 뒤에 붙는 부분입니다.

### config.json 예시

```json
{
  "db_path": "data/pokewatch.db",
  "delay": 0.8,
  "port": 8765,
  "cafes": [
    {
      "name": "포켓몬카드 카페",
      "cafe_url": "카페주소",
      "menu_name_filter": ["장터", "거래", "판매"],
      "pages": 3,
      "per_page": 50
    }
  ]
}
```

| 항목 | 설명 |
|---|---|
| `cafe_url` | 카페 주소. 숫자 `club_id` 를 이미 알면 `"club_id": 12345678` 로 대신 써도 됩니다. |
| `menu_ids` | 수집할 게시판 ID 목록. `menus` 명령으로 확인합니다. |
| `menu_name_filter` | ID 대신 게시판 **이름**에 포함된 단어로 고릅니다. |
| `pages` | 게시판별 수집 페이지 수 (한 페이지 최대 50건). |
| `delay` | 요청 사이 대기 시간(초). 줄이지 마세요. |

### 회원 전용 게시판

로그인해야 보이는 게시판은 브라우저 쿠키가 필요합니다. 로그인한 상태에서 개발자 도구의
Network 탭 요청 헤더에 있는 `NID_AUT`, `NID_SES` 값을 복사해 환경변수로 넘기세요.

```bash
export POKEWATCH_COOKIE="NID_AUT=...; NID_SES=..."
python3 -m pokewatch collect
```

쿠키는 로그인 세션 그 자체이므로 절대 저장소에 커밋하지 마세요. 그래서 설정 파일보다
환경변수를 우선하도록 만들어 두었습니다.

## 4. 대시보드에서 볼 수 있는 것

- **카드 격자 보기** — 카드 이미지(글 썸네일), 이름/영문명/도감번호, 레어도·언어·감정 배지,
  중앙값 가격, 최저~최고 범위, 최근 시세 스파크라인, 상승/하락률
- **표 보기** — 같은 내용을 정렬 가능한 표로
- **카드 상세** — 일자별 중앙값 그래프, 거래 유형/상태 분포, 원본 글 목록(클릭 시 카페로 이동)
- **필터** — 검색어, 거래 유형(판매/구매/교환), 레어도, 언어, 기간, 감정 카드만, 일괄 제외
- 상단 **새로 수집** 버튼으로 대시보드를 켜 둔 채 다시 수집할 수 있습니다.

시세 계산은 **판매글의 단일 카드 가격만** 사용합니다. 구매 희망가와 일괄 판매가는
실제 시세를 왜곡하기 때문에 중앙값 계산에서 빠지고, 상세 화면에는 그대로 보입니다.

글에 썸네일이 없으면 레어도 색으로 칠한 대체 카드 이미지를 그려서 보여 줍니다.

## 6. 제목 해석 방식

한국 장터 글 제목에서 다음을 뽑아냅니다.

| 항목 | 인식 예 |
|---|---|
| 거래 유형 | 판매/팝니다/분양, 삽니다/구합니다, 교환, 나눔 |
| 가격 | `12만`, `12.5만`, `12만5천`, `85,000원`, `120000`, `55k`, `12~15만` |
| 레어도 | SAR, SR, AR, UR, HR, CHR, CSR, RR, ex, V, VMAX, VSTAR, GX, 프로모, 풀아트 |
| 언어 | 한글/한판/정발, 일판/일본, 영문/미판 |
| 감정 | PSA 10, BGS 9.5, CGC, ARS |
| 상태 | 미개봉, 민트/S급, 니어민트/A급, 플레이드/흠집 |
| 부가 정보 | 세트 코드(SV5a), 카드 번호(165/165), 수량, 택포, 일괄, 네고 |

가격처럼 생겼지만 가격이 아닌 숫자는 걸러냅니다. 카드 번호(`165/165`), 감정 점수(`PSA 10`),
수량(`10장`), 연도(`2024년`)가 대표적입니다. `가격제시`, `쪽지주세요` 같은 표현이 있으면
가격 미기재로 둡니다.

### 같은 카드로 묶는 기준

`카드이름 | 레어도 | 언어` 를 키로 씁니다. 세트 코드와 카드 번호는 일부 글에만 적혀 있어서
키에 넣으면 같은 카드가 잘게 쪼개집니다. 언어를 안 적은 글은, 그 카드의 언어가 한 가지뿐일
때만 그쪽으로 합치고 한글·일판이 섞여 있으면 `미표기`로 따로 둡니다.

### 카드 이름 사전 넓히기

`pokewatch/data/pokemon_ko.json` 에 포켓몬 약 180종과 서포트 카드가 들어 있습니다.
자주 거래되는데 인식이 안 되는 카드가 있으면 이 파일에 추가하고 다시 해석하세요.

```bash
python3 -m pokewatch reparse   # 다시 수집하지 않고 저장된 제목만 재해석
```

## 7. 명령어 목록

| 명령 | 설명 |
|---|---|
| `init` | `config.json` 템플릿 생성 |
| `menus <카페주소>` | 게시판 목록과 ID 조회 |
| `collect` | 설정된 카페에서 글 수집 |
| `serve` | 대시보드 실행 |
| `demo` | 예제 데이터 생성 후 대시보드 실행 |
| `top` | 터미널에서 시세 상위 카드 보기 |
| `parse "<제목>"` | 제목 하나의 해석 결과 확인 |
| `export` | 정적 사이트로 내보내기 (핸드폰용 호스팅) |
| `reparse` | 저장된 제목을 현재 파서로 재해석 |

`serve` 는 앱처럼 쓰기 위한 옵션이 있습니다.

```bash
python3 -m pokewatch serve --open              # 브라우저 자동 실행
python3 -m pokewatch serve --lan               # 휴대폰에서도 접속 가능
python3 -m pokewatch serve --auto-collect 60   # 60분마다 자동 수집
```

주요 환경변수: `POKEWATCH_COOKIE`, `POKEWATCH_DB`, `POKEWATCH_PORT`, `POKEWATCH_CONFIG`

## 8. 설치용 앱으로 묶기 (선택)

파이썬이 없는 컴퓨터에서도 실행되는 단일 실행 파일을 만들 수 있습니다.

```bash
pip install pyinstaller
python3 -m PyInstaller packaging/pokewatch.spec
```

- 맥 → `dist/포켓몬카드시세.app`
- 윈도우 → `dist/포켓몬카드시세.exe`
- 리눅스 → `dist/포켓몬카드시세`

대시보드 화면과 카드 이름 사전이 실행 파일 안에 함께 들어갑니다.
**크로스 컴파일은 안 됩니다** — 맥용 앱은 맥에서, 윈도우용 exe 는 윈도우에서 만들어야 합니다.

앱 아이콘을 바꾸고 싶으면 `tools/make_icons.py` 의 `draw_icon()` 을 고친 뒤 실행하세요.
홈화면 아이콘(PNG)과 실행 파일 아이콘(`.ico`, `.icns`)이 한 번에 다시 만들어집니다.

## 알아 두실 점

- **시세는 참고용입니다.** 글 제목에서 자동으로 뽑은 호가라서, 실제 체결가와 다르고
  허위 매물이나 오타가 섞일 수 있습니다. 매물 수가 적은 카드일수록 오차가 큽니다.
- **개인적인 시세 확인 용도로만 사용하세요.** 요청 간격(`delay`)을 줄이거나 대량으로
  긁지 마세요. 카페 운영 정책과 `robots.txt` 확인, 로그인 쿠키 관리는 사용자 책임입니다.
- 네이버가 내부 API 응답 형식을 바꾸면 수집이 실패할 수 있습니다. 그럴 때는
  `python3 -m pokewatch -v collect` 로 로그를 확인하세요.
- 시세를 거르고 묶는 계산은 파이썬(`stats.py`)과 브라우저(`web/data.js`) 양쪽에
  있습니다. 한쪽만 고치면 결과가 어긋나므로 `tools/check_parity.py` 가 두 결과를
  대조합니다 (테스트에 포함되어 있습니다).
- 이 저장소가 만들어진 환경에서는 네이버 도메인이 네트워크 정책으로 차단되어 있어,
  **수집기는 실제 카페 응답으로 검증하지 못했습니다.** 파싱·집계·대시보드는 예제
  데이터와 단위 테스트로 검증했습니다. 처음 `collect` 를 돌릴 때는 `-v` 로 로그를 보며
  `pages` 를 1로 두고 시작하시길 권합니다.
